# Farnsworth House / Three.js 建築モデル

ファンズワース邸を公開資料に基づいて作成した、メートル単位のインタラクティブ建築習作です。実測・保存修復・施工用モデルではありません。

## 起動

1. Node.js が使える環境で `start.cmd` を実行してください。
2. または、このフォルダで `node server.cjs` を実行し、http://127.0.0.1:4173 を開いてください。
3. 停止するときはサーバーのターミナルで Ctrl+C を押します。

外部通信は不要です。Three.js r180 と必要なアドオンを `vendor/` に同梱しています。HTMLを直接ダブルクリックするとブラウザのES Modules制限により動きません。上記サーバーを使ってください。ポートを変える場合は `PORT` 環境変数を指定できます。

## 操作

- ドラッグ：回転。右ドラッグ：平行移動。ホイール：ズーム。タッチでは1本指で回転、2本指でズームと移動。
- 外観・室内・平面・ディテールの視点切替。室内表示もOrbitControlsによる操作で、衝突判定のある歩行モードではありません。
- 屋根・ガラス・家具・カーテン・樹木・寸法の表示切替。
- 屋根の持ち上げ、昼光・夕景・薄暮、自動回転。
- 部材または素材スウォッチをクリックして素材の説明を表示。
- GLB書き出し：建物・家具・カーテンを組立状態で保存。画面で非表示にした部材も含みます。敷地・照明・寸法は含みません。
- 画像保存：現在の3DビューをPNG保存。操作UIは含みません。

付属サーバーでの保存先は同じフォルダの `farnsworth-house.glb` と `farnsworth-house.png` です。再保存時はその名前のファイルを更新します。一般の静的HTTPサーバーでは通常のブラウザダウンロードに切り替わります。

## 寸法とモデル構成

| 項目 | モデル値 |
|---|---:|
| 主屋＋ポーチ | 23.546 × 8.738 m |
| 主床仕上げ高さ | 1.600 m |
| 天井高 | 2.896 m |
| 柱間隔 | 6.706 m |
| 外周柱 | 8本、外形203 mmのH形断面 |
| 床・屋根の縁 | 381 mm |
| 下段テラス | 16.840 × 6.909 m |
| 下段床高さ | 0.864 m |
| トラバーチン厚 | 31.8 mm |
| 目地 | 約1.6 mm |
| ガラス厚 | 6.35 mm |

座標系はY-up、+Xが東、−Zが北、1単位=1mです。階段、ガラス割付、東面の下部小窓、キッチン、暖炉、設備コア、浴室、独立収納、カーテンのひだ、参考家具のクッションと金属フレームを含みます。

## 正確さと近似の境界

主要寸法と構法はHABSの建築記述、平面構成は同測量図を参照しています。資料の年代や寸法基準に差があるため、異なる資料の値が完全に一致するとは限りません。床高さは地形・スラブ下面と仕上げ面の区別に注意して1.600mを採用しました。完全な実測点群やCADトレースではなく、コードから生成するモデルです。

以下は近似です。

- 柱フランジ・ウェブ厚、金物、下部梁、階段支持材、設備配管と屋根設備。
- コアの詳細寸法と内部器具。キッチンのシンクは奥行きの錯覚を使った簡略形状です。
- 家具の種類・寸法・配置。ミース家具を使った後年の展示を想起させる参考配置で、1951年の暮らしや特定展示年の厳密な復元ではありません。
- 石材・木材・布・革は手続き生成のテクスチャで、現物スキャンのPBRマップではありません。ガラスはリアルタイム描画用の透過・透明度を併用しています。
- 樹木・地形は雰囲気を示すものです。植栽調査や正確な敷地配置を表しません。
- 照明は演出用。太陽軌道計算、熱環境計算、光学的に厳密なパストレーシングは実施していません。

## 編集とライセンス

建築パラメータ・モデル生成・照明・操作は `app.js`、画面は `index.html` と `style.css`、起動と保存は `server.cjs` にあります。パッケージインストールやビルドは不要です。

GLBの石床は通常のメッシュに展開しており、インスタンシング拡張に非対応のソフトでも読み込めます。ガラスの透過拡張とバンプ拡張への対応は読み込み先に依存します。Three.jsはMITライセンスです。`vendor/LICENSE` を同梱しています。参照図や写真はモデルへの貼り付け素材として使用していません。
